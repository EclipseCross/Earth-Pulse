# Demo data
Place preprocessed REAL NISAR metadata here as `*.json`:

```json
{"observations": [{"granule_id": "...", "product": "GUNW",
  "acquisition_start": "2026-01-01T00:00:00Z", "bbox": [w, s, e, n], "download_url": "..."}]}
```
Nothing is shipped in Phase 1 because no real NISAR granule has been retrieved yet. Do not add synthetic data under a NASA label.
